# המרכז להכשרת אנליסטים פונדמנטליים ואוריינות פיננסית ב-AI
**Capital Markets & Financial AI Learning Hub**

אפליקציית Web מודרנית (Single-Page Application) בעברית (RTL) להכשרה, תרגול, מעבדת AI אינטראקטיבית מול Google Gemini 1.5 Flash ומבחן הסמכה מסכם עבור סטודנטים ואנליסטים בשוק ההון.

מותאמת באופן מלא לשיגור ב-**GitHub Pages** ללא צורך בסביבת שרת או Build מורכב.

---

## 🚀 תכונות מרכזיות ומבנה המסכים

1. **מסך 1: הזדהות והגדרות אישיות (Welcome & Onboarding)**
   - הזנת שם התלמיד הנשמר ב-`localStorage` ומלווה אותו אישית בכל חלקי המערכת.
   - הגדרת מפתח Google Gemini API אישי הנשמר בדפדפן בלבד (Client-side Security) לבדיקת קישוריות.
   - סקירת ארכיטקטורת מסלול ההכשרה.

2. **מסך 2: יחידות לימוד ותרגול מודרך (Lessons & Guided Practice)**
   - **מודול 1: שלושת הדוחות הכספיים** – מאזן (נכסים, התחייבויות, הון עצמי, הון חוזר), דוח רווח והפסד (שולי רווח, מדרגות רווחיות), ודוח תזרים מזומנים (CFO, CFI, CFF) ותרשים זרימה אינטראקטיבי.
   - **מודול 2: יחסים פיננסיים והערכות שווי** – מכפיל רווח וסכנת Value Traps, ROE מול ROIC (חפיר כלכלי ומינוף), רכישות עצמיות (Buybacks) מול דילול, עקרונות DCF ומחשבון ROIC אינטראקטיבי.
   - **מודול 3: מקורות אמת ואוריינות דיווח** – ניווט במערכת מאיה (בורסת ת"א), SEC EDGAR (טופסי 10-K, 10-Q, 8-K), וכלל ה-Grounding למניעת הזיות של מודלי שפה.
   - **מודול 4: תרגול מודרך (10 שאלות)** – פידבק מיידי עם סימון ירוק/אדום, ופירוט מעמיק מתקפל המסביר הן את התשובה הנכונה והן את הסיבה המדויקת מדוע כל אחת מ-3 החלופות האחרות שגויה.

3. **מסך 3: מעבדת Gemini AI אינטראקטיבית (Financial Playground)**
   - תבניות פרומפטים פיננסיים מקצועיים (בדיקת איכות רווח CFO vs רווח נקי, זיהוי סעיפים חד-פעמיים בביאורים, מנועי צמיחה ומרווח גולמי, לוח סילוקין חוב).
   - כפתור להזנת נתוני דוח כספי לדוגמה (קומפיו-טק מערכות בע"מ) בלחיצה אחת.
   - ממשק שיחה רב-שלבי (Multi-Turn Chat) עם מודל `gemini-1.5-flash` התומך ברינדור Markdown מלא של טבלאות ונוסחאות.
   - אפשרות לאתגר את המודל בשאלות המשך ביקורתיות.

4. **מסך 4: מבחן הסמכה מסכם (Final Certification Exam - 20 שאלות)**
   - תנאי בחינה קפדניים (ללא פידבק מיידי וללא רמזים).
   - 100 נקודות משוקללות במדויק:
     - שאלות 1-5 (קל): 4 נקודות כ"א (סה"כ 20 נק')
     - שאלות 6-15 (בינוני): 5 נקודות כ"א (סה"כ 50 נק')
     - שאלות 16-20 (מאתגר): 6 נקודות כ"א (סה"כ 30 נק')
   - סרגל מעקב שאלות ודיאלוג אישור לפני הגשה.

5. **מסך 5: תוצאות, תעודת הסמכה ושיגור למרצה (Results & Submission)**
   - ציון סופי (0-100) ופילוח ביצועים לפי 3 קטגוריות תוכן (דוחות כספיים, יחסים והערכות שווי, אוריינות AI ומקורות).
   - תעודת הסמכה דיגיטלית מעוצבת הניתנת להדפסה ולשמירה כ-PDF בלחיצה אחת (`window.print`).
   - כרטיס שיגור ל-Google Forms ישירות באמצעות `fetch(..., { mode: 'no-cors' })` ו-iframe נסתר לעקיפת מגבלות CORS, עם נעילת שם וציון והזנת מייל התלמיד:

     - Student Name: `entry.231853524`

     - Final Score: `entry.1691612376`
   - סקירה מלאה של כל 20 שאלות המבחן עם תשובת התלמיד, התשובה הנכונה והסבר מפורט.

## 🌐 פריסה ב-GitHub Pages

1. העלה את תוכן התיקייה ל-Repository ב-GitHub.
2. בהגדרות ה-Repository, היכנס ל-**Settings** -> **Pages**.
3. תחת **Branch**, בחר `main` (או `master`) ובתיקייה בחר `/ (root)`.
4. שמור (Save). האתר יעלה לאוויר בכתובת:
   `https://<your-username>.github.io/<repo-name>/`

## 🔑 שימוש ב-Google Gemini API
האפליקציה פונה ישירות למודל Google Gemini באמצעות REST API סטנדרטי:
`https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=...`
המפתח מוזן על ידי המשתמש ונשמר ב-`localStorage` בדפדפן המקומי בלבד. ניתן להשיג מפתח בחינם ב-[Google AI Studio](https://aistudio.google.com/app/apikey).
